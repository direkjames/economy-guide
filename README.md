# The Economy Guide

Keep the coins flowing and the prices fair: a plain-words guide to running a Minecraft server economy.

![Status](https://img.shields.io/badge/status-active-brightgreen) ![Site](https://img.shields.io/badge/site-GitHub%20Pages-blue) ![Format](https://img.shields.io/badge/also-PDF-orange)

## About

The Economy Guide is a wiki and a downloadable PDF for people who run Minecraft servers with a money system. It explains where coins come from, where they should go, how to spot inflation early and how to keep things fair for every player. It is written for owners and staff, in short sentences, with numbers you can use as a starting point.

A friendly gold nugget named Nugget guides you through it.

## Features

- A full guide covering the basics, currency design, pricing, income sources (faucets), money drains (sinks), taxes, inflation, markets, fair play and exploits
- Separate advice for Oneblock, Survival and a Cobblemon modpack
- A plugin-neutral list of what to look for in economy, shop, auction and jobs tools
- An interactive Health Check that turns a few weekly numbers into a plain verdict
- A weekly staff checklist that remembers your progress in your browser
- Every formula in one place, with worked examples
- Search, light and dark mode, and a layout that works on phones
- A downloadable PDF of the whole guide

## Getting started

1. Open the website, or download the PDF from the button in the top bar.
2. New to economies? Start with **How a server economy works**, then read **Golden rules**.
3. Already running a server? Open **Economy health check**, type in this week's numbers and follow the advice.
4. Use the **Weekly checklist** every week.

### Running it on your own computer

1. Install [Node.js](https://nodejs.org) 20 or newer.
2. Open a terminal in this folder.
3. Run `npm run dev`.
4. Open `http://localhost:4173` in your browser.

### Updating the PDF

1. Edit the pages in the `content` folder.
2. Run `npm run pdf`. It needs Microsoft Edge or Google Chrome installed.
3. Commit the new `downloads/economy-guide.pdf` along with your changes.

### Publishing

1. In the repository settings, open **Pages** and set the source to **GitHub Actions**.
2. Push to `main`. The site is built and published automatically.

## Requirements

- Node.js 20 or newer to build the site
- Microsoft Edge or Google Chrome only if you want to rebuild the PDF
