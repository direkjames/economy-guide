---
title: Glossary
desc: Every economy word used in this guide, in plain language.
---

| Term | Meaning |
| --- | --- |
| **Active player** | A player who logged in during the period you are measuring, usually the past 7 days |
| **Admin shop** | A server-run shop where players buy from and sell to the server |
| **AFK** | Away from keyboard. A player who is idle but still earning |
| **Alt account** | A second account owned by the same person |
| **Arbitrage** | Buying something in one place and selling it for more in another |
| **Auction house** | A player market where items are listed for sale |
| **Basket** | A fixed list of common items used to measure price changes |
| **Burn** | Remove coins from the game permanently |
| **Cap** | A limit on how much a player can earn or sell in a period |
| **Catch-up** | Mechanics that help new players close the gap to veterans |
| **Currency reform** | Changing the scale of money, such as dividing all balances and prices by 10 |
| **Deflation** | Money becomes scarce and prices fall, or players cannot afford things |
| **Diminishing returns** | Each extra action earns a bit less than the one before |
| **Dupe** | A bug that copies items or money |
| **Exploit** | Using a bug or loophole to gain an unfair advantage |
| **Faucet** | Anything that creates new coins |
| **Floor and ceiling** | The lowest and highest price an item is allowed to have |
| **Hoarding** | Holding large amounts of money or items without using them |
| **Hourly rate** | How much an hour of normal play should earn |
| **Inflation** | The same item costs more and more coins over time |
| **Loop** | A chain of trades or crafts that ends with more coins than it started with |
| **Money supply** | All the coins that exist at a given moment |
| **Monopoly** | One player controlling most of a market |
| **Price index** | A single number that tracks the average price of the basket over time |
| **Recycle** | Return collected coins to players through events or prizes |
| **Sink** | Anything that permanently removes coins |
| **Spread** | The gap between what the shop charges and what it pays |
| **Starter kit** | Free items given to new players |
| **Treasury** | A server account that collects taxes and fees |
| **Velocity** | How fast money changes hands |
| **Wash trading** | Two accounts trading back and forth to dodge tax or fake activity |
| **Wealth tax** | A small recurring tax on large balances |
